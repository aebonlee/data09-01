**온라인에서 바로 쓰기: https://hdx-ps.jobability.co.kr/** (옛 주소 https://aebonlee.github.io/data09-01/ 는 이 주소로 넘어갑니다)

### 로그인과 회원 (2026-09-30)

1. **구글 또는 카카오로 로그인**합니다(드림아이티비즈 공용 회원 — 따로 비밀번호를 만들지 않습니다).
2. 처음 한 번 **내 정보**에 이름·전화번호·딜러 여부(딜러면 딜러사명)·국가·지역을 적습니다.
3. **관리자가 승인**하면 기술지원 화면을 씁니다. 그 전까지는 「승인 대기」 안내만 보입니다.
4. 관리자(PS 담당자)는 「회원 관리」에서 승인·반려·사용 중지·권한·관리 지역을, 「매뉴얼 등록」에서 매뉴얼 색인을 올립니다.
5. **제공 자료** — 수강생이 준 원본 파일(기획안·DB 엑셀·화면구성·답변·대응표·매뉴얼 PDF)은 비공개 저장소에 두고, 승인 회원은 「제공 자료」에서 내려받기(10분짜리 서명 주소), 관리자는 여러 파일을 한 번에 올리기·지우기를 합니다. 리포에는 넣지 않습니다.

- 화면 언어는 머리의 **KO | EN** 단추로 바꿉니다(처음에는 브라우저 언어를 따름, 고른 언어는 기억).
- 파일로 연 화면(`file://`)에서는 로그인할 수 없고, 아래 예시 데이터 시연만 됩니다.
- **기술지원 기록(등록·문의·회신·소스·PS 메일·접속 Log)은 서버 표(`data0901_*`)에 저장됩니다**(v0.8). 정비사는 자기 건, 관리자는 모든 회원의 건과 접속 Log 를 봅니다. 로그인하면 「첫 화면」에 흐름과 현황(기록에서 센 숫자)이 보입니다.
- 서버 표는 강사가 `supabase/2026-09-30_data0901_records.sql` 을 SQL Editor 에서 한 번 실행해야 생깁니다. 그 전에는 화면 위에 「서버 기록 준비 전」 띠가 뜨고 예전처럼 이 브라우저에 저장됩니다. 브라우저에 쌓인 기록은 관리자가 「데이터 → 브라우저 기록 서버로 올리기」로 한 번 옮깁니다.

### 시연(로그인 없이)

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 데이터가 비어 있습니다. 로그인 화면의 **「예시 데이터 불러오기」** 를 누르면 시연용 가상 데이터가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

| 예시 계정 | 권한 | 쓰임 |
|---|---|---|
| `demo_user01` | USER | 정비사(경기) — 등록·후속 요청·조회·종료 |
| `demo_eu01` | USER | 정비사(Europe) — 해외 지역 메일 배정 시연 |
| `demo_new01` | USER | 가입 신청 후 **승인 대기** — 관리자가 「회원 관리」에서 승인해야 들어갈 수 있습니다 |
| `demo_admin` | ADMIN | PS 담당자(관리 지역: 국내 5개 + Direct Sales) — 전체 조회·AI 회신·회원 승인·메일 대기·소스 등록·접속 Log |
| `demo_admin_gl` | ADMIN | 해외 PS 담당자(관리 지역: 해외 7개) |

- 시연 데이터는 **이 브라우저(localStorage)에만** 저장됩니다(서버 기록과 섞이지 않음). 보관·이동은 「데이터」 메뉴의 엑셀 내보내기/가져오기로 합니다.
- 예시 파일: `samples/예시데이터_기술지원DB.xlsx`(시트 7개 — 메일 시트 포함) 와 시트별 CSV. 모두 가상 데이터입니다.
- 로직 테스트: `node test/logic.test.mjs`, `node test/profile-i18n.test.mjs` (기본 정보 검증·두 언어 문구 짝 맞춤), `node test/originals.test.mjs` (제공 자료 경로·형식이 서버 SQL 과 짝), `node test/server-db.test.mjs` (서버 행 변환·바뀐 것 고르기·브라우저 기록 옮기기·SQL 과 짝) — 의존성 없음 / 색 대비: `node scripts/check-contrast.mjs` / SQL 검증: `./scripts/sqltest/run.sh` (임시 로컬 PostgreSQL)
- **매뉴얼 PDF 는 이 저장소에 없습니다**(회사 저작물). 승인 회원은 관리자가 「매뉴얼 등록」으로 올린 매뉴얼(쪽별 텍스트 색인, 비공개 저장소)을 「매뉴얼 근거」에서 바로 씁니다. 내 PC 의 PDF 를 골라 브라우저 안에서만 읽는 방식도 그대로 됩니다. PDF 가 크면 `python3 scripts/manual_to_json.py <PDF 또는 폴더>` 로 쪽별 텍스트 JSON 을 만들어 불러와도 됩니다(결과 JSON 도 커밋하지 않습니다).
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 로그인·언어 선택 | 완료 | **구글·카카오 로그인**(공용 Supabase, 09-30 강사 결정), 한국어/English 전 화면 전환(KO/EN 단추, 국문/영어 2종 확정 — 수강생 확인 09-28), USER/ADMIN 권한별 메뉴 |
| 회원 등록·승인 | 완료(서버) | 로그인 → 기본 정보(이름·전화번호·딜러 여부·딜러사명·국가·지역) → 승인 대기 → 관리자 「회원 관리」에서 승인·반려·사용 중지·권한·관리 지역. 승인·권한은 DB 가 관리자만 바꾸게 막음(`data0901_profiles`). 수강생 답변 09-29 + 강사 결정 09-30 |
| 기술지원 등록(기술지원1) | 완료 | 모델·호기·가동시간·유형·구분·현상·요청사항, ref_no 자동 채번(yyyymmddnnnn), 상태 Submitted, 첨부 파일명 `ref_no_일련번호` 기록. 유형 코드는 `Specification` 으로 통일(옛 엑셀의 오타는 가져올 때 고침) |
| 첨부 제한 | 완료 | 제출 1회마다 사진 최대 5장·영상 1개, 영상 60초 이하(파일을 고를 때 영상 길이를 읽어 확인, 못 읽으면 경고만). 수강생 확인 09-28 |
| 모델 입력 검증 | 완료 | 소스등록에 없는 모델이면 팝업 안내(등록 모델 목록 표시) |
| 후속 요청(기술지원2·3) | 완료 | 최근 1달 본인 등록 건 팝업 → 기존 내용 불러와 수정·재제출, s_turn 증가. 종료된 건은 다시 열지 않음(새 지원 요청으로) |
| AI 1차 회신 | 완료(반자동) | 접수 내용으로 프롬프트 자동 생성 → NotebookLM/Dify 답변 붙여넣기 → r_title·req_summary·reply_content·ref_info 로 나눠 저장, 상태 Answered. API 자동 회신은 2단계 |
| 근거 페이지 보기 | 완료(글자) | 근거 칩(예 `15BRP-X SM EXP p.7-170`)을 누르면 불러온 매뉴얼의 그 쪽 본문, 이전/다음 쪽. 그림 그대로 보는 PDF 뷰어는 2단계 |
| 매뉴얼 근거 검색 | 완료 | 내 PC 의 매뉴얼 PDF → 브라우저 안 추출(pdf.js, 파일로 열어도 동작) 또는 `scripts/manual_to_json.py` JSON → 목차(SECTION·Group, 두 단 목차, 숫자 쪽 표기)·키워드 검색·쪽 보기. **접수 모델 → 소스 등록 대응표 → 해당 매뉴얼을 먼저 검색**(09-29 저녁, 수강생 대응표 31개 모델, 받은 매뉴얼 18종 목차 확인 — 목차와 본문 쪽이 어긋난 매뉴얼은 제목으로 찾아 맞춤, `7-23-1` 끼워 넣은 쪽 표기). AI 회신 화면에서 접수 내용으로 검색 낱말을 만들고 고른 쪽 발췌를 프롬프트에 붙임. 내 PC 에서 불러온 매뉴얼은 어디에도 올라가지 않음(IndexedDB). 09-29 · **관리자 「매뉴얼 등록」 → 승인 회원이 서버의 매뉴얼 색인을 바로 검색**(비공개 버킷 `data0901-manuals`, PDF 원문은 올리지 않음) 09-30 |
| 제공 자료(원본 보관) | 완료(서버) | 수강생이 준 원본 27개(문서·엑셀 9 + 매뉴얼 PDF 18)를 비공개 버킷 `originals/` 에 — 관리자는 여러 파일 한 번에 올리기(메모·덮어쓰기)·지우기, 승인 회원은 10분짜리 서명 주소로 내려받기. 강사 결정 09-30 |
| 기술지원 조회(User) | 완료 | 등록일 기간·모델 검색, 본인 건만, 더블클릭(또는 Enter)으로 상세조회, 추가 요청, 조치 결과 적고 종료 |
| 기술지원 조회(Admin) | 완료 | 등록일 기간·모델·딜러·분류·고장 유형 검색, 접수 횟수·이름·딜러·회신 내용·완료일·조치 내용 열, CSV 내보내기 |
| AI 답변 불가·중복 등록 시 관리자 메일 | 완료(발송 대기) | `[답변불가]` 답변과 같은 모델·호기 중복 등록 건을 요청자 지역 담당 관리자 앞 메일로 만들어 「메일 대기」 목록에 쌓음 → 메일 앱으로 열기(mailto)·복사·보냄 표시. 정적 웹이라 직접 발송은 하지 않음(메일 서버 키를 공개 코드에 둘 수 없음). 자동 발송(Make)은 2단계 |
