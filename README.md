# data09-01 · 지게차 AI 기술지원 플랫폼

현장 정비사의 기술 문의를 정형 양식으로 접수하고 모델별 정비 매뉴얼 기반 AI가 1차 회신, 미해결 건은 PS 담당자에게 넘기며 문의·회신을 DB로 축적하는 기술지원 시스템

|---|---|
| 제출자 | 김봉수 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
