## 결정과 이유

- **필드명은 수강생 최신 DB(04_DB.xlsx, 09-28)를 그대로 썼습니다.** 시트 이름(등록·문의·회신·사용자·소스등록·Log Data)과 필드명(ref_no, s_turn, r_turn, o_hour …)이 엑셀 내보내기의 시트·머리행과 같습니다. 수강생이 가진 엑셀을 그대로 가져올 수 있도록, 가져오기는 맨 위 제목 행(「Main Data」)과 코드 안내 행을 건너뜁니다.
- **화면은 화면구성.xlsx 10개 시트를 따랐습니다.** 조회_User 9열, 조회_Admin 12열의 순서, 검색조건, 「더블클릭 → 상세조회」, 상세조회_User 의 「추가 요청」, 상세조회_Admin 의 「소스 등록(기준 정보 자동 입력)」을 그대로 옮겼습니다. 휴대폰에서는 더블클릭이 어려워 행을 선택하고 Enter 로도 열리게 했습니다.
- **상세조회는 요청·회신을 차수 순서로 번갈아 보이는 대화형**으로 했습니다. 설계서 문구 「기술지원 요청 사항과 AI 답변 사항 정리」와 PRD 의 「채팅 버블형 UI」를 함께 따른 것입니다.
- **상태 색은 수강생 정의대로** 접수=빨강, 회신=파랑, 종료=검정입니다.
- **상태 전환 규칙**: 신규·후속 요청 제출 → Submitted, 회신 저장 → Answered, 정비사가 「해결됨 — 종료」 → Completed. 회신이 없는 건은 종료할 수 없습니다. Flowchart 의 「해결 → 종료」를 버튼으로 옮긴 것입니다.
- **AI 회신은 반자동**입니다. 관리자 상세조회에서 접수 내용·이전 회신·답변 형식(`[제목] [요약] [회신] [근거]`)을 담은 프롬프트를 만들어 주고, NotebookLM/Dify 답변을 붙여 넣으면 네 필드로 나눠 확인 후 저장합니다. 답변에 `[답변불가]` 가 있으면 PS 통보 메일 초안을 만듭니다(발송은 사람이 합니다).
- **파일은 저장하지 않고 파일명만 기록합니다.** 사진·영상·매뉴얼 PDF를 브라우저 저장소에 넣으면 용량 한도(보통 5MB)를 곧 넘고, 매뉴얼은 보안 등급이 높은 자료라 브라우저에 복사해 두지 않는 편이 맞습니다. 첨부 파일명은 DB 정의대로 `ref_no_일련번호.확장자` 로 바꿔 기록하고, 후속 요청에서도 번호가 이어집니다.
- **모델 검증은 대소문자를 가리지 않고**, 저장할 때는 소스등록에 있는 표기로 맞춥니다(`30brp-x` → `30BRP-X`). 표기가 달라 같은 모델이 둘로 갈리는 것을 막기 위함입니다.
- **스크립트를 ES module 이 아닌 일반 스크립트로** 불러옵니다. `index.html` 을 파일로 열면(file://) 브라우저가 module 스크립트를 막아 화면이 통째로 비기 때문입니다. `logic.js` 는 Node 테스트에서도 같은 파일을 불러 씁니다.
- **회사명·주소·사업자번호 푸터는 넣지 않았습니다.** 기획서 10장 11번에서 표기 여부가 확인 필요로 남아 있습니다.

## 가정

- type_cd 원본의 「Specificatio」는 오타로 보고 `Specification` 으로 통일했습니다. 엑셀 가져오기 때도 자동으로 고칩니다(기획서 10장 5번 확인 필요).
- 09-08 초안의 Reference Data(근거 여러 행)는 쓰지 않고, 최신본대로 회신 행의 `ref_info` 한 칸에 `;` 로 여러 근거를 넣습니다. 최신본 크기가 VARCHAR(50)이라 근거가 여러 개면 넘칠 수 있습니다 — 확정 필요.
- 「1달간」은 달력 기준 한 달 전 같은 날부터 오늘까지로 잡았습니다(3월 31일 → 2월 말일부터).
- 후속 요청에서는 모델·호기·가동시간·유형·구분도 고칠 수 있게 하고, 마지막 제출값으로 등록(Main Data) 행을 갱신합니다. 문의 이력은 차수별로 남습니다.
- 사용자 시트의 password 는 저장하지 않습니다. 1단계는 이 브라우저 안의 시연판이라 비밀번호 확인을 하지 않고, 화면에 그렇게 적었습니다. 평문 비밀번호를 엑셀·브라우저에 두지 않기 위함입니다.
- 필드 정의에 크기가 없는 phenomenon·requirement 는 길이 제한을 두지 않았습니다.
- 사용자 필드명은 사용자 시트의 `req_name` 을 따랐습니다(필드 정의 시트에는 `reg_name` 으로 적혀 있어 확인 필요).
